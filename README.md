# Floating-Labels-for-Form-Inputs
# 🛡️ Simple Login System with HTML, CSS & JavaScript

This project is a fully functional user login and registration interface built with pure HTML, CSS, and JavaScript — no frameworks or libraries required.

---

## ✨ Features

- ✅ Login (Username & Password)
- 🆕 Account Registration
- 👁️ Toggle Password Visibility
- 🔐 Password Reset Functionality
- 🚪 Logout Capability
- 💾 Stores user data using `localStorage` (no external database)
- 🧼 Clean and Responsive UI

---

## 🧪 How to Use

1. Download or clone the repository.
2. Open the `index.html` file in your browser.
3. Register a new user.
4. Log in using the credentials you just created.
5. Try logging out, resetting the password, or toggling views.

---

## 📂 Project Structure

All the logic and styling are included in a **single HTML file** for simplicity:

- `index.html` — contains full markup, styles, and JavaScript.

---

## 🧠 Technical Notes

- User credentials are stored locally in the browser via `localStorage`.
- This project is intended for **educational/demo purposes** only and should not be used in production environments without additional security layers like encryption and a proper backend.
